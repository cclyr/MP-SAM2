# Checkpoints

Checkpoint files are intentionally excluded from Git. The local release package
contains the following files:

- `mp_sam2_5_seed42.torch`
- `mp_sam2_10_seed42.torch`
- `mp_sam2_50_seed42.torch`
- `mp_sam2_full.torch`
- `sam2.1_hiera_large.pt` (official Meta base checkpoint; local use only)

The public weight download will be added after acceptance of the associated paper.
The original SAM2 base checkpoint must be obtained under Meta's SAM2 license.
