# Contributing

Issues and pull requests are welcome after the repository becomes public.

1. Create a focused branch from the default branch.
2. Keep raw ECC data, videos, annotations, and model weights out of Git.
3. Run `python -m compileall mp_sam2 scripts sam2` before submitting.
4. Document new configuration parameters and preserve specimen-level split safety.
5. Add a small reproducible test or example for behavioral changes.

Please use the existing code style, provide clear commit messages, and report the
Python, PyTorch, CUDA, and GPU versions used for experimental results.
